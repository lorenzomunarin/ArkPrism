# ArkPrism

**Interactive ArkTS Compiler & Real-Time Bytecode Visualizer for HarmonyOS**

ArkPrism is an interactive, open-source developer tool engineered specifically for the HarmonyOS and OpenHarmony ecosystems. It enables real-time manipulation of ArkTS source code while directly interfacing with the ArkCompiler to optimize, disassemble, and inspect generated bytecode on the fly.


## Key Features

* **Interactive Code Manipulation:** Modify ArkTS source files dynamically and immediately observe compiler pipeline updates.
* **Real-Time Bytecode Disassembly:** Direct integration with ArkCompiler to output intermediate representation (IR) and disassembled bytecode instantly.
* **Optimization Inspection:** Inspect individual optimization passes and low-level code generation to fine-tune high-performance ArkTS applications.
* **Native Ecosystem Integration:** Built specifically around OpenHarmony and HarmonyOS toolchains, targeting ArkCompiler runtime dynamics.


## Architecture & Workflow

ArkPrism hooks into the standard ArkCompiler toolchain pipeline:

1. **Source Analysis:** Parses and feeds ArkTS source snippets directly into the compiler frontend.
2. **Execution Control:** Triggers specific optimization flags and compilation passes via command-line arguments and low-level interfaces.
3. **Bytecode Extraction:** Intercepts generated bytecode artifacts (`.abc`) and passes them through real-time disassembling routines for immediate developer feedback.
